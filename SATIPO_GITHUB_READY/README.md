# Spectral convergence without ecological equivalence — Satipo, Peru

Research materials supporting the manuscript **“Spectral convergence without ecological equivalence: Decoupling of biodiversity, forest architecture and biomass in Amazonian forests.”**

## Contents

- `notebooks/satipo_analysis_development.ipynb`: source analysis notebook, with saved outputs removed and an infinite keep-alive loop excluded. The original analytical code and iterative development cells are otherwise preserved.
- `figures/main/`: editorial main figures in PDF format (Figures 2–9; **Figure 1 is not included**).
- `figures/supplementary/`: supplementary figures in PDF format.
- `tables/`: analytical and editorial Excel workbooks.
- `manifests/`: editorial tracking files.

## Reproducibility status — IMPORTANT

**This is a curated research archive, not yet a verified one-click reproducibility package.** The notebook contains exploratory and successive revision cells, expects datasets/checkpoints not included in this release, and uses Google Colab, Google Drive, and Google Earth Engine. It has **not** been executed from a fresh environment. The included workbooks are analytical outputs, not a substitute for all raw input data.

To reproduce analyses, obtain authorized original forest inventory files, spatial boundaries, wood-density reference datasets and the full research archive, then adapt the notebook paths and configure Google Earth Engine. Check that the manuscript's figures and tables correspond to the final selected versions.
